# AI Tools for AIML

## Project Overview

This project provides a simple list of useful AI tools that can support learning, coding, AIML, and Data Analytics.

## AI Tools Included

- ChatGPT – AI assistance and learning
- GitHub Copilot – Code suggestions
- Google Gemini – AI research and analysis
- Microsoft Copilot – AI productivity
- Google Colab – Python and ML experiments

## Technologies Used

- Python

## Purpose

The purpose of this project is to understand how different AI tools can be useful for students and developers in AIML and Data Analytics.

## Files

- `ai_tools.py` – Python script containing the AI tools and their uses
- `requirements.txt` – Required Python package
